The CSV keeps the USGS column names because it's a data file for Python. The JSON uses short camelCase keys because TypeScript code reads them, and camelCase is the JavaScript convention.

How to build it:
1. Rename the columns with df.rename(columns={...}).
2. Turn the rows into a list of dicts with .to_dict(orient="records").
3. Wrap that list in the outer object with element and units.
4. Write it to data/samples_cu.json with Python's built-in json.dump.

Why SiteID was float in the real data

The units row has a blank for SiteID (only Latitude and Longitude say Degrees). pandas reads axists for floats, so the whole column became float64. Dropping the units row doesn't change the type back. That's why your mocks (which say This there) gave strings and the real file gave floats. With your .astype(int) fix, both come out as int.
